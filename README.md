A Linux-based Autonomous Mobile Robot (AMR) developed using the ROS2 ecosystem on a Jetson Nano for high-level computing, seamlessly integrated with an ESP32 microcontroller over micro-ROS for low-level, real-time motor execution. The system implements SLAM fusion via LiDAR and a USB Camera to construct precise environmental maps, while leveraging the Nav2 stack for intelligent autonomous pathfinding and dynamic obstacle avoidance. This project showcases a robust hardware-software co-design tailored for modern industrial logistics and autonomous navigation
